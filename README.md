# pvpeluso

Repositório pessoal de projetos Python, organizado por área.

## Estrutura

| Pasta | Descrição |
|-------|-----------|
| `automacao/` | Scripts de automação de tarefas, bots e ferramentas |
| `dados/` | Análise de dados, visualizações e ETL |
| `scripts/` | Scripts utilitários e ferramentas de linha de comando |
| `estudos/` | Exercícios, algoritmos e material de aprendizado |
| `jogos/` | Jogos e projetos de entretenimento em Python |
| `web/` | APIs, backends e projetos web |

## Como usar

Cada pasta contém seu próprio `README.md` com instruções específicas.
